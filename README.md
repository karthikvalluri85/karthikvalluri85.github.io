## How this site is built

A single, dependency-free `index.html`: hand-written HTML and CSS, Google Fonts, and a small canvas animation for the hero lineage graph. It supports light and dark mode and respects reduced-motion settings. Hosted free on GitHub Pages.

## Updating

- **New repo:** copy the block marked `PLACEHOLDER: copy this block for each future repo` in `index.html`.
- **New article:** copy the block marked `PLACEHOLDER: copy this block for each new post`.
- **New certification:** add a line under `PLACEHOLDER: add new certifications here`.
- **CV:** upload `cv.pdf` to this repo and follow the comment above the nav button.

Commit the change and the site updates in a minute or two.
